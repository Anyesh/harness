# Reexplain

Take your immediately preceding response (the one the user couldn't digest) and say it again in plain, everyday human language.

## Rules

- **At most three short sentences, plain prose, no headers, no bullet lists.** This overrides the usual header-plus-bullets response format. Say it the way you'd say it out loud to a person standing next to you.
- **If it can't be said in three short sentences,** give only the first piece and stop. Wait for the user to react or say "next" before continuing. Do not dump the rest in the same message.
- **Keep going back and forth**, one small piece at a time, until the user confirms they've actually got it. The goal is that they understood it, not that you said it.
- **No jargon carried over unexplained.** If a term from the original response matters, explain it in one plain clause inline rather than assuming it landed the first time.

This is a one-off request, not a standing mode: once the user confirms they've got it, go back to responding normally.
