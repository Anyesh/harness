# Reexplain

Take your immediately preceding response (the one the user couldn't digest) and say it again in plain, everyday human language.

## Rules

- **A few sentences only.** No headers, no bullet lists, no restating the original's structure. Say it the way you'd say it out loud to a person standing next to you.
- **If it genuinely doesn't fit in a few sentences,** give only the first piece and stop. Wait for the user to react or say "next" before continuing. Do not dump the rest in the same message.
- **Keep going back and forth**, one small piece at a time, until the user confirms they've actually got it. Digestion, not delivery, is the finish line.
- **No jargon carried over unexplained.** If a term from the original response is load-bearing, explain it in one plain clause inline rather than assuming it landed the first time.

This is a one-off request, not a standing mode: once the user confirms they've got it, go back to responding normally.
