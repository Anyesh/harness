# Composition patterns

Pick one structure type per shot. Match the type to the idea, then invent a fresh
metaphor inside it. The type is scaffolding, never written on the image.

- Workflow: left input, center processing (crow plus machine), right output. Orange
  arrows carry the flow left to right.
- System cutaway: 3-5 modules of a larger system shown at once. The crow works one
  critical module while the rest sit quiet.
- Before / after: left is the broken or chaotic state, right is the ordered state, one
  orange arrow between them. The crow can be exaggerated on each side.
- Role / state: 2-4 small vignettes of the crow in different states, each with a short
  label. Good for "modes" or "stages of a process".
- Concept metaphor: one large strange object or machine as the central metaphor, minimal
  inputs, one output. The most memorable type, spend the metaphor here.
- Layered method: stacked boxes for method tiers or system layers, not a formal pyramid.
  The crow is actively building or climbing the stack.
- Map / route: a winding path with a few labeled nodes. The crow walks or guides along it.
- Mini comic: 2-4 panels, one action each. Use for a failure arc, a success arc, or a
  short process walkthrough.
